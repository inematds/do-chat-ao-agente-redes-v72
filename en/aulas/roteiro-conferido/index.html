Lesson 5 · 17 min

60-second script with the source on screen

With the base ready, the agent writes the script, and only from what is in the base. The radar opens with the date and the strongest number, covers each topic with the profile card of who said it, and ends with a question and the invitation. Before it becomes a video, the script goes through the check: if a number isn't in the base, the script goes back.

Start the lesson

In this lesson you will

  3. 3The request to the agent, ready to copy
  4. 4The list of what fails a script

Goal: ask the agent for a 60-second script from the base.md and send it back whenever a number isn't in the base.

02 · The speech rules

Each one came from a rejected video. The checar.py checks several of them on its own.

1. Spelled out

All numbers and years are spelled out in the speech. The check rejects digits in the speech.

Spoken linesete vírgula sete por cento · dois mil e vinte e oito

2. How it's spoken

Acronyms are read the way they are spoken. A government address has no "ponto": "consumidor gov bê érre". On screen it stays consumidor.gov.br.

Rejected on 10/13/2026"consumidor ponto gov ponto bê erre"

3. You

Address the viewer as "você" (you), with short sentences. The check rejects "tu," "teu" and "tua."

Spoken lineThis changes what you pay at the end of the month.

4. Anchor without a number

Each visual comes in on an ordinary word of the speech (the anchor), never on a number: the avatar's transcript writes numbers as digits, so the anchor would not match.

Anchor"aluguel" yes · "doze" no

03 · The script request and the gate checklist

Paste your base.md and your rules into the request. Then check it against the list.

request to the agent
Write the script for a 60-second vertical video using ONLY the
numbers and facts from the base.md below. Do not use the internet or any other source.

Structure:
1. Opening: the shock line with the strongest number (never "Imagine,"
   "Hello" or "In this video").
2. Three facts, each with who said it, the video and the date on screen.
3. The mandatory niche notice (it is in regras.md).
4. A question that invites comments.
5. The closing invitation, to one destination only.

Rules: address the viewer as "você"; numbers and years spelled out in the speech; every
number shown must be in the base.md. If the base does not have enough
material, answer only SEM PAUTA and the reason.

<paste the base.md>
<paste the regras.md>
portao-roteiro.md
- [ ] Every number on screen is in the base.md (with a literal excerpt)
- [ ] No number written as digits in the speech
- [ ] Opening with the strongest number, without "Imagine/Hello/In this video"
- [ ] Source (channel, date, title) in every scene with a fact
- [ ] Mandatory niche notice present
- [ ] Addresses the viewer as "você"
- [ ] Second-to-last line: comment question
- [ ] One destination only in the closing invitation

Failed: the script goes back once. Failed again: no video today.
Example from the repository
  • each excerpt from the base is in the transcript of the cited video;
  • numbers written as digits in the speech;
  • images exist;
  • CTA to inema.club in the last line;
  • the niche notice sentence;
  • "tu/teu/tua" in the speech and "gov" with "ponto".

The radars' prompt says to write all the files or only SEM_PAUTA.txt. When there is no material, the bot receives "sem pauta" and the reason. That is better than forcing a weak video.
